# State rules schema (for the Flutter app and the dashboard)

Status: **contract v2 (implemented and tested)**, Oct 22, 2026. Schema and RPCs: migration `20261023120900_ll_state_rules_v2.sql`. Data: `20261023121000_ll_state_rules_data.sql` (generated by `scripts/build_state_rules_seed.py` from the research CSV). The app can mirror these shapes 1:1. Field names are final; new fields may be added later but existing ones won't be renamed.

**Plain-language summary:**
- Each US jurisdiction (50 states + DC) has one or more **rule set** rows in `public.state_rule_sets`, one per *version*. A version applies to permits issued in a date window.
- The backend picks a student's rule set from their **state** and their **permit issue date** (`students.permit_on`).
- All hours are stored in **minutes** (integers). The app converts for display. `log_unit` says whether the state's own form counts in hours or minutes.
- `null` always means **"no such rule" or "not known"**, never zero. Check `status` and `field_status` to tell those two apart.
- The data comes from `/workspace/state-driving-logs/` (official sources, checked 2026-10-22). Nothing is invented: unknown or blocked values are `null`, with a note in `field_status`.

## 1. `public.state_rule_sets` (readable by any signed-in user)

| column | type | meaning |

| `id` | uuid | Row id. Students may pin one via `students.rule_set_id`. |
| `state_code` | text(2) | `TX`, `DC`, … (upper case) |
| `jurisdiction_name` | text | `Texas`, `District of Columbia` |
| `version` | int | 1, 2, … per state |
| `effective_from` | date | First **permit issue date** this version applies to. `2000-01-01` = "all permits on record" |

| `label` | text | Short title, e.g. `Texas 30-hour behind-the-wheel log` |
| `status` | text | `verified` (official source checked) · `partially_verified` (some fields or links unconfirmed; see `field_status`) · `unconfirmed` (no official source, e.g. HI) |
| `verified` / `verified_on` | bool / date | Legacy flags. `verified = (status = 'verified')`, `verified_on = last_checked` |
| `last_checked` | date | Date the research was last checked against official sources |
| `requirement_kind` | text | What the law requires you to hand in: `log` (the log itself) · `log_any_format` (any log with the required info, NM) · `certification` (only a signed statement of total hours) · `none` (no hours requirement: AR, MS) · `unconfirmed` |
| **Hours** | | |
| `total_minutes` | int, null | Total supervised driving. `null` = none or unknown |
| `night_minutes` | int, null | Night minutes (part of the total) |
| `night_rule` | text | `sunset_sunrise` · `half_hour_after_sunset` (½ h after sunset to ½ h before sunrise) · `after_sunset` · `darkness` · `unspecified` · `clock_window` (uses `night_start`/`night_end`) |
| `night_definition` | text | The state's wording, verbatim from the research |

| `weekly_cap_minutes` | int, null | Most minutes that count per week (NC 600). Weeks run Monday to Sunday by the drive's local date |
| `log_unit` | text | `hours` or `minutes` (MN, NV forms count minutes). Display only |
| **Instructor time** | | |
| `lessons_count` | bool | Do signed instructor lessons (`drives.kind = 'lesson'`) count toward the total? |
| `instructor_multiplier` | numeric | Each counted instructor minute is worth this many minutes (WI 2) |
| `instructor_max_minutes` | int, null | Most **raw** instructor minutes that may count (WI 300 = 5 h, so up to 600 credited; CO 360) |
| **Stages and alternatives** | | |
| `stages` | jsonb array | Multi-stage requirements (IA, MI). See section 2 |
| `alternatives` | jsonb array | Other totals that apply in some cases (OR driver ed, MD age 25+, …). See section 3 |
| **Supervisor** | | |
| `supervisor_min_age` | int, null | TX 21, NH 25, CT 20, … |
| `supervisor_min_years_licensed` | numeric, null | TX 1, CT 4, WA 3, OK 2, SD 1, … |
| `supervisor_parent_exempt` | bool | true: a licensed parent or guardian doesn't need to meet the age rule (NH: "licensed parent/guardian **or** licensed adult 25+") |
| `supervisor_rule` | text | The state's wording |
| **Paperwork** | | |
| `notarization` | text | `required` (AZ FL OH OK RI SD) · `if_signer_absent` (IL, AK: notarize only if the parent can't come in person) · `not_stated` |
| `notarization_note` | text | e.g. `notary or MVD agent`, `notary or DL examiner` |
| `digital_log` | text | `accepted` (NC MT MI NM NH: a digital or printed app log is OK) · `listed_apps` (only the named apps, see `digital_log_apps`; NV, OH) · `not_stated` |
| `digital_log_apps` | text[] | e.g. `{RoadReady}` |
| `digital_log_note` | text | e.g. NV: only DLD-130 or RoadReady; other logs are not accepted |
| `form_type` | text | `full_log` (the state publishes a per-drive log) · `certification` (an affidavit of totals only) · `none` (no downloadable form) · `unconfirmed` |
| `form_type_detail` | text | Raw description, e.g. `full log (optional) + certification on permit` |
| `form_name` / `form_number` | text | e.g. `Texas 30 Hour Behind the Wheel Log` / `DES150N (TDLR)`. `''` if none |
| `form_pdf_url` / `form_pdf_status` | text | Official PDF and its link check, e.g. `verified (HTTP 200, %PDF)` |
| `alt_form_name` / `alt_form_pdf_url` | text | A second official form, if any |
| `form_code` / `form_url` | text | Legacy copies of `form_number` / `form_pdf_url` |
| **Links** | | |
| `handbook_url`, `parent_guide_url`, `gdl_page_url`, `source_url` | text | Official pages (`''` if none) |
| `link_status` | jsonb | `{"form_pdf": "...", "handbook": "...", "parent_guide": "...", "gdl_page": "...", "source_page": "...", "alt_form_pdf": "..."}` (the verification text for each link) |
| **Notes** | | |
| `other_rules` | text | Everything else the state says (permit holding period, who signs, where to submit), verbatim from the research |
| `notes` | text | Research notes |
| `field_status` | jsonb | Per-field caveats, e.g. `{"night_minutes": "from official log category, not statute"}`, `{"total_minutes": "unconfirmed"}` |
| `pending_change_on` / `pending_change_note` | date / text | A known future change that isn't modelled yet (VA 2027-01-01) |

### How a student's rule set is chosen
1. If `students.rule_set_id` is set (pinned by school/staff), that row is used.
2. Otherwise: same `state_code` as the student, with `effective_from <= d` and (`effective_to` is null or `> d`), where `d = students.permit_on`, or today if the permit date is unknown. If several match, the newest `effective_from` wins, then the highest `version`.
3. No match → no rule. The app shows "No rule on file for {state} for a permit issued {date}".

Versions in the data today:
- **NJ v1** (`unconfirmed`, before 2025-02-01): the earlier requirement wasn't in the research. **NJ v2**: 50 h / 10 night for permits on or after 2025-02-01.
- **WI v1**: 30 h for permits before 2021-07-11 (night and instructor rules not in the research → `null` / not counted). **WI v2**: 50 h / 10 night from 2021-07-11, instructor ×2 up to 5 h.
- **SD v1**: from 2020-07-01, which is the only window in the research.

## 2. `stages` JSON (array, ordered)

```json
[
  { "key": "intermediate",
    "label": "Before the intermediate license",
    "total_minutes": 1200, "night_minutes": 120, "weather_minutes": null,
    "counting": "cumulative" },
  { "key": "full",
    "label": "While on the intermediate license, before the full license",
    "total_minutes": 600, "night_minutes": 120, "weather_minutes": null,
    "counting": "since_previous_milestone",
    "milestone": "intermediate" }
]
```
- `counting = "cumulative"`: minutes from the first drive onward count, and the numbers are cumulative targets. MI: 30 h / 2 night before Segment 2 is part of the overall 50 / 10.
- `counting = "since_previous_milestone"`: only drives on or after the date the student reached `milestone` count, and the numbers are *additional* minutes (IA: 10 more h / 2 more night after getting the intermediate license).
- The milestone date comes from `public.student_rule_milestones` (`student_id`, `milestone_key`, `reached_on`), set with `set_rule_milestone()`. If it isn't recorded, the backend uses **the day after** the previous stage was completed (signed practice drives, daily cap applied) and returns `"milestone_assumed": true`. Until the previous stage is complete, the stage shows 0 credited and `window_from: null`. `set_rule_milestone` accepts a stage's `milestone` or its `key`.
- The top-level `total_minutes` / `night_minutes` are always the overall goal (IA 30 h / 4 night, MI 50 h / 10 night).

## 3. `alternatives` JSON (array)

```json
[
  { "key": "driver_ed",
    "label": "Completed ODOT-approved driver education",
    "total_minutes": 3000, "night_minutes": null, "weather_minutes": null,
    "replaces_hours": false }
]
```
- A student opts in with `set_rule_alternative(student_id, key)` (stored in `students.rule_alternative`). Clear it with `null`.
- A `null` field in an alternative means "same as the base rule". `replaces_hours = true` means that path has no hours target at all. For example, AL: driver ed completion is submitted instead of the 50 h.
- Data today: AL, AZ, MA, MD, MN, OR.

## 4. Per-student data the rules use

| where | field | used for |
|---|---|---|
| `students.state_code`, `students.permit_on` | — | Choosing the rule version |
| `students.rule_alternative` | text, null | The chosen `alternatives[].key` |
| `drives.night_minutes` | int | Night minutes. The app computes them from the state's `night_rule` |
| `drives.weather_minutes` | int (new) | Minutes driven in inclement weather (rain, snow, ice, fog). `0..duration_minutes`; locked once signed. Also tag `drives.conditions`, e.g. `{"Rain"}` |
| `drives.kind` | `practice` / `lesson` | Lessons count only if `lessons_count`, with the instructor multiplier and cap |
| `supervisors.birth_date`, `supervisors.licensed_since` | date, null (new) | Supervisor age and experience checks |
| `student_rule_milestones` | table (new) | Stage dates (IA intermediate license date, MI Segment 2) |

**Supervisor rule at sign-off:**
- If the student's rule has `supervisor_min_age` or `supervisor_min_years_licensed`, and the chosen supervisor's `birth_date` or `licensed_since` is **known and too young or too recent**, `sign_drive()` fails with error `22023` and a message such as "In NH the supervisor must be at least 25 (licensed parents and guardians excepted)".
- A parent or guardian is excused from the age rule when `supervisor_parent_exempt` is true.
- The experience rule fails with "In TX the supervisor must have been licensed at least 1 year(s)".
- Unknown dates don't block sign-off, but they're counted in `supervisor.unverified_drives` in the progress response.
- `supervisors.licensed_since` can't be before `birth_date` (error 23514).

## 5. The hours math (what "credited" means)

The steps, in order:
1. **Which drives count:**
   - signed `practice` drives
   - signed `lesson` drives, but only when `lessons_count` is true
   - pending drives are reported separately, as `pending_minutes`
2. **Per local day** (practice drives):
   - `day = min(minutes, daily_cap)`
   - `night_day = min(night, day)`
   - `weather_day = min(weather, day)`
3. **Per week** (only if `weekly_cap_minutes`):
   - `week = min(Σday, weekly_cap)`
   - night and weather are clipped to `week` the same way
4. **Instructor lessons:**
   - `counted = min(Σlesson minutes, instructor_max_minutes)`
   - `credited = counted × instructor_multiplier`
   - Lesson night minutes count once (no multiplier), and only up to `counted`.
   - Caps apply to practice drives only.
5. **Totals:**
   - `total = practice credit + instructor credit`
   - `night = practice night + lesson night`
   - `weather` = practice weather; or, when `weather_counts_night`, `challenging = min(night + weather, credited)` per day
6. **Stages and alternatives** use the same math, over their own date window and targets.

## 6. RPC: `student_rule_progress(p_student_id uuid) → jsonb`

Callable by anyone who can see the student. It's what the app and the export render.

```json
{
  "student_id": "…",
  "rule": { "id": "…", "state_code": "TX", "jurisdiction_name": "Texas", "version": 1,
            "label": "…", "status": "verified", "requirement_kind": "log",
            "effective_from": "2000-01-01", "effective_to": null,
            "selected_by": "permit_date",           // "override" | "permit_date" | "today"
            "permit_on": "2026-04-14", "log_unit": "hours" },
  "alternative": null,                              // or { "key": "driver_ed", "label": "…", "replaces_hours": false }
  "caps": { "daily_minutes": 120, "weekly_minutes": null, "capped_days": 1, "capped_weeks": 0 },
  "instructor": { "counts": false, "multiplier": 1, "max_minutes": null,
                  "raw_minutes": 120, "counted_minutes": 0, "credited_minutes": 0 },
  "requirements": [
    { "key": "total",   "label": "Total supervised driving", "required_minutes": 1800,
      "credited_minutes": 564, "pending_minutes": 180, "remaining_minutes": 1236, "met": false },
    { "key": "night",   "label": "At night",                 "required_minutes": 600, "credited_minutes": 120, "pending_minutes": 0, "remaining_minutes": 480, "met": false },
    { "key": "weather", "label": "In inclement weather",     "required_minutes": 300, "credited_minutes": 0, "pending_minutes": 0, "remaining_minutes": 300, "met": false }
  ],
  "stages": [
    { "key": "intermediate", "label": "…", "counting": "cumulative", "milestone": null,
      "window_from": null, "milestone_assumed": false, "met": true,
      "requirements": [ { "key": "total", … }, { "key": "night", … } ] }
  ],
  "all_met": false,
  "still_needed": [ "20 h 36 m more in total", "8 h more at night" ],
  "supervisor": { "min_age": 21, "min_years_licensed": 1, "parent_exempt": false, "rule": "…", "unverified_drives": 3 },
  "paperwork": { "form_type": "full_log", "form_name": "…", "form_number": "DES150N (TDLR)", "form_pdf_url": "…",
                 "notarization": "not_stated", "notarization_note": "", "digital_log": "not_stated", "digital_log_apps": [] }
}
```
**Rules for reading this response:**
- Requirement keys are `total`, `night`, `weather`, and `challenging` (AK only). A requirement only appears when its target is not `null`.
- When `requirement_kind` is `none` or `unconfirmed`, `requirements` is empty and `still_needed` explains why.
- `student_hours_summary()` (older, flat) still works and uses the same math. `requirement_met` = `all_met` (false when unknown).
- `rule` also carries `night_rule` and `field_status`.
- `student_hours_by_day()` adds `raw_weather_minutes`, `weather_credited_minutes`, `week_start` (Monday) as new last columns. Practice drives only, daily cap applied; weekly caps are reported in `caps`.
- `list_drives()` adds `weather_minutes` as its new last column.

## 7. RPC: `state_resources(p_state_code text, p_permit_on date default null) → jsonb`

This is the resources screen. It needs no student.

```json
{
  "state_code": "NV", "jurisdiction_name": "Nevada", "rule_set_id": "…", "version": 1, "status": "verified",
  "summary": "50 h of supervised driving, including 10 h at night. Logged in minutes (3,000 / 600).",
  "requirements": { "total_minutes": 3000, "night_minutes": 600, "weather_minutes": null, "daily_cap_minutes": null,
                    "weekly_cap_minutes": null, "log_unit": "minutes", "stages": [], "alternatives": [] },
  "supervisor": { "min_age": null, "min_years_licensed": null, "parent_exempt": false, "rule": "" },
  "form": { "type": "full_log", "type_detail": "…", "name": "Beginning Driver Experience Log", "number": "DLD-130",
            "pdf_url": "…", "pdf_status": "verified (HTTP 200, %PDF)", "alt_name": "", "alt_pdf_url": "",
            "notarization": "not_stated", "notarization_note": "",
            "digital_log": "listed_apps", "digital_log_apps": ["RoadReady"], "digital_log_note": "…" },
  "links": [ { "kind": "form_pdf", "label": "…", "url": "…", "status": "…" },
             { "kind": "handbook", … }, { "kind": "parent_guide", … }, { "kind": "gdl_page", … }, { "kind": "source_page", … } ],
  "checklist": [ { "step": 1, "key": "log_hours", "text": "Log 50 h (10 at night)…" },
                 { "step": 2, "key": "official_form", "text": "…" }, … ],
  "how_to_use_licenselogger_log": "official_form_only",
  "other_rules": "…", "notes": "…", "field_status": {}, "last_checked": "2026-10-22",
  "pending_change": null
}
```
`requirements` also includes `night_rule`, `night_definition`, `weather_counts_night`, `lessons_count`, `instructor_multiplier`, `instructor_max_minutes`. The top level also has `effective_from`, `effective_to`, `requirement_kind`. `links` only lists links that exist (`kind` is one of `form_pdf`, `alt_form_pdf`, `handbook`, `parent_guide`, `gdl_page`, `source_page`; `source_page` is skipped when it's the same as `gdl_page`). Checklist `key`s: `log_hours`, `caps`, `weather`, `stages`, `alternatives`, `instructor`, `supervisor`, `official_form`, `notary`, `confirm`, `pending_change`. `state_resources` needs a signed-in user; an unknown state raises `P0002`.

`how_to_use_licenselogger_log` is app guidance derived from the fields above, not a legal statement:
- `submit_printout`: digital or any-format logs are accepted
- `official_form_only`: only the state form or the listed apps
- `copy_to_official_form`: the state requires its own log, so use LicenseLogger as a worksheet and copy the entries over
- `records_only`: only a certification is required; the log backs up the parent's signature
- `none`: no hours requirement
- `unconfirmed`

`my_rule_resources(p_student_id)` returns the same shape for the student's chosen rule (state and permit date), plus `"progress"` (the section 6 object).

## 8. Write RPCs for the app

| RPC | who | does |
|---|---|---|
| `update_my_student(p_student_id, …, p_state_code, p_permit_on)` | independent students and their family | Sets the state and permit date, which choose the rule |
| `set_rule_alternative(p_student_id, p_key text)` | the student, family or school desk | `p_key` must be one of the rule's `alternatives[].key`, or `null` |
| `set_rule_milestone(p_student_id, p_key text, p_reached_on date)` | the student, family or school desk | Records a stage date (`p_reached_on = null` deletes it) |
| `drives.weather_minutes` | the normal drive update | Set before sign-off; locked afterwards |
| `supervisors.birth_date`, `licensed_since` | the normal supervisor insert/update | Optional; used by the sign-off check |
